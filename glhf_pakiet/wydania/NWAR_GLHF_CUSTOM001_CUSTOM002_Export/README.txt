GLHF CUSTOM001 + CUSTOM002 export

Extract this folder inside the NWAR folder that contains app, runtime and launcher.json.
Double-click Export CUSTOM001 and CUSTOM002.cmd. The dashboard can remain open.
The script only reads the saved runs; it does not stop/start STAR or change the queue.
It creates one verified ZIP in NWAR/GLHF_exports, including both latest saved SIM files,
all continuation-segment CSV histories, validation receipts and saved .simh field histories.
The success message is EXPORT COMPLETE with the full ZIP path.
Move that generated ZIP to the NTNU project folder on Google Drive for import on ThinkPad.
If a selected run is still calculating, wait for its final save before exporting.
If the checkpoint predates the last force sample, the exact mismatch is recorded explicitly.
Export does not grant scientific acceptance.
